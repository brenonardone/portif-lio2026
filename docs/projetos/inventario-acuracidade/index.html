Detalhamento por rua

Sistema = posições que o WMS tinha como ocupadas · Limpar = alocado no sistema, sem palete físico · Entrada = palete físico achado, sem alocação no sistema.

Rua Sistema Corretos Limpar (erro) Entrada % Erro Acuracidade
Metodologia: a rua de cada posição foi tomada pela letra inicial do código de alocação (coluna "Alocado"), já que é o código físico de endereço (ex.: A0102 = rua A) usado igualmente nas três abas da planilha. "Corretos" = Sistema − Limpar. Acuracidade = Corretos ÷ (Sistema + Entrada) — os paletes físicos achados sem alocação no sistema ("Entrada") também entram como divergência na base de cálculo, já que representam estoque real não refletido no WMS. A rua Y (54 posições, 100% corretas) apareceu na planilha vinculada às posições de baixa da rua I e não constava na lista de ruas conferidas — vale confirmar se é uma sub-área da rua I ou um endereço à parte antes de fechar o relatório.
